## Questionable items (included, flag for review)

1. **Harness model name.** `gpt-6.1-sol` appears in summaries and `paper/COST_TIME.md` as the model the platform
   resolved for the harness. A fact of the study; naming a third-party model in a public repo is a choice.
2. **Image tags and digests without registry.** `harness:local-…` tags, OCI digests and short commit hashes of an
   internal repository remain in the protocol and summaries (A15–A22). They identify builds, not hosts.
3. **Harness defect and fix descriptions.** `results/runs/*/HARNESS_DEFECTS.md`, the protocol (A15–A20) and
   `results/summaries/RERUN_SUMMARY.md` describe harness defects (D1–D5) and the fixes in each image (R2–R11), and the
   re-run summary cites internal issue labels. Not secrets, but engineering detail of an internal product.
4. **Internal platform vocabulary.** Builder notes and summaries mention platform internals (`integration-designer`,
   `maker-files`, the planner, `ComposeScript`, session phases, the `fxc` CLI, `tools/harness_api.py`), and the
   methods log mentions a node-pool upgrade and an internal service restart.
5. **Builder notes quote the platform version** ("platform 5.13") and tool names of the FlowX.AI MCP server.
6. **`isolation.txt`** shows the builder's own memory paths (`~/.claude/projects/-HOME-…`), revealing the local
   directory naming of the study (`carddemo-builds`, `ll-builds`).
7. **Interventions log.** `results/runs/a21/interventions.log` and `a19h/interventions.log` record re-logins and a
   hung client, with times. They are the disclosure the protocol requires.
8. **Symlinks.** `results/runs/A5_golden/`, `A16_golden/`, `A21_golden/` are relative symlinks (recreate with
   `tools/link_a5_golden.sh`, `tools/link_cr_golden.sh`).
9. **References to files not in this repository.** The protocol, summaries and hash files cite the lab notebook, build
   drivers and platform session records; the README says so. Paths use the study layout (`runs/`, `builds/inputs/`).
10. **Frozen files that verify as files:** the pre-registration package, A5/A6, A7, the withdrawn A5/A6 file and the A21
    manifest. From A12 on, only the recorded hash can be checked against the stamp.
