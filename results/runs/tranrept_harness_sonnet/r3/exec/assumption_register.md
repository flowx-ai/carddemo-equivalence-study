# Assumption ledger (extracted verbatim from the workflow scripts' assumption() calls)

1. **A01**: Read ASCII-compatible fixed-width text, with LF or CRLF separators and at most one final newline. Require record lengths 350, 50, 60 and 60 respectively. Do not perform EBCDIC conversion. _Basis:_ tranrept-sonnet.pdf p.26: "Fixed-width text, one record per line, layouts as in the copybooks". Character encoding and newline handling are not specified.
2. **A02**: Infer Transaction positions: ID 1-16; type 17-18; category 19-22; source 23-32; description 33-132; implied-cent signed amount 133-143; merchant ID 144-152; name 153-202; city 203-252; ZIP 253-262; card 263-278; original timestamp 279-304; processing timestamp 305-330; filler 331-350. These offsets are inferred, not copybook-verified. _Basis:_ tranrept-sonnet.pdf pp.8-9 list the transaction attributes, order and widths; p.26 specifies CVTRA05Y and 350 characters but does not reproduce the copybook.
3. **A03**: Infer CardXref card/customer/account widths 16/9/11; TransactionType code/description widths 2/50; TransactionCategory type/category/description widths 2/4/50. Treat the remaining record tails as filler. _Basis:_ tranrept-sonnet.pdf pp.8-10 give these field orders and widths; p.26 gives total record lengths 50/60/60. Exact filler positions are absent.
4. **A04**: Decode implied-cent amounts as unsigned digits or ASCII signed overpunch: {ABCDEFGHI are positive digits 0-9 and }JKLMNOPQR negative digits 0-9. Accumulate and format integer cents without floating-point decimal summation. _Basis:_ tranrept-sonnet.pdf p.8 identifies TRAN-AMT S9(9)V99; p.9 mentions signed overpunch for another legacy field. The transaction input encoding is not explicitly stated.
5. **A05**: Default the inclusive report range to 2022-07-01 through 2022-07-31, overriding the older wiki defaults. Supplied ISO calendar dates override those defaults. Compare calendar dates without timezone conversion. _Basis:_ tranrept-sonnet.pdf p.26: "daily transaction report start date 2022-07-01 and end date 2022-07-31"; p.2 gives older defaults and requires processedTimestamp selection inclusive.
6. **A06**: Sort lexically by the fixed-width numeric card number and retain input order within each card. Do not deduplicate transactions. _Basis:_ tranrept-sonnet.pdf p.2: "Sorted by card number". No secondary sort or transaction deduplication is specified.
7. **A07**: Print at most 50 transaction details per page. Headings, totals and rules do not consume that quota. Repeat the four-line heading on each page. _Basis:_ tranrept-sonnet.pdf p.19: "page size {{TODO: lines per page in CBTRN03C}}"; p.29 specifies the four-line page heading but no page limit.
8. **A08**: Treat Account Total as the card-break total, carried across page breaks, not an aggregation of all cards sharing an account. At simultaneous card and page boundaries print account total and rule before page total and rule. _Basis:_ tranrept-sonnet.pdf p.2 says "card total (on card change)"; p.19 says "Account total ... per account/card (break on card number)". The relative boundary ordering is absent.
9. **A09**: Close the final page with page total and rule, then grand total. An empty selection prints one heading, zero page total and rule, then zero grand total, without an account total. Do not append a rule after grand total. _Basis:_ tranrept-sonnet.pdf p.4: "Empty range ... Report with zero total"; p.29 requires a rule after each page and account total, but does not completely specify final/empty ordering.
10. **A10**: Look up category by type plus category. Print UNKNOWN TYPE or UNKNOWN CATEGORY for missing descriptions and account 00000000000 for missing card cross-reference; flag each lookup error and retain the transaction and amount. _Basis:_ tranrept-sonnet.pdf p.4: "Type missing in reference data ... Error flagged, run continues"; p.10 identifies the category composite key. Missing-xref behaviour and placeholder text are not specified.
11. **A11**: Accept repeated lookup keys only when their meaningful values agree; reject conflicting duplicates rather than choose arbitrarily. _Basis:_ tranrept-sonnet.pdf pp.8-10 identify lookup keys; duplicate-record resolution is not documented.
12. **A12**: Fail without a partial report for missing files, malformed fixed-width records, invalid dates or numeric fields, a reversed date range, conflicting lookup records, unsafe arithmetic, or a printed amount exceeding the numeric picture. _Basis:_ tranrept-sonnet.pdf pp.2,4,26-29 do not define these invalid-input and overflow behaviours. Failing rather than silently dropping financial data is an implementation choice.
13. **A13**: Space-pad every report line to 133 characters and truncate textual display fields to their contracted widths. Monetary fields have a fixed first-position sign, leading zero groups/commas suppressed, blank positive detail sign and explicit positive total sign. Zero prints .00 with the applicable sign. _Basis:_ tranrept-sonnet.pdf pp.27,29 specify picture notation, columns and signs. The zero edge case and text overflow handling are not fully specified.
14. **A14**: Return tranrept_report as an ordered list of printed lines and assumptions.md as companion Markdown text in one result, rather than writing to an unspecified external folder. Inputs remain unchanged. _Basis:_ tranrept-sonnet.pdf p.26 explicitly permits a list of strings under the output filename without extension. No external output destination is supplied.
15. **A15**: Use a model only to draft the paired assumption explanations from this inventory. Preserve all approved facts and source bases; if drafting fails or cannot be validated, use the complete canonical entries and disclose the fallback. Never let drafting alter the financial report. _Basis:_ Implementation default: the wiki does not prescribe how an assumptions document is authored or how drafting failures are handled.
16. **A16**: Validate the first ten characters of both transaction timestamps as ISO calendar dates. Use only the processing-date portion for selection; the remaining timestamp characters are not interpreted. _Basis:_ tranrept-sonnet.pdf p.9 gives DateTime fields X(26); p.2 filters on processing date. The timestamp time/fraction grammar and timezone conversion are not specified.
